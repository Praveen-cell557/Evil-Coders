## ✨ About

**Evil Coders** is a community and learning platform for anyone who wants to understand how systems break so they can protect them. We teach hacking tools and ethical hacking through hands-on practice, guide beginners from zero, and help learners reach internships and jobs.

This repository contains the official website, built as a single, dependency-free HTML file.

## 🎯 What we offer

- **Ethical hacking:** the full penetration testing lifecycle (Nmap, Metasploit, Kali Linux)
- **Web exploitation:** OWASP Top 10, Burp Suite, SQLmap
- **Network security:** Wireshark, Aircrack-ng, network hardening
- **Malware analysis:** Ghidra, YARA, x64dbg in safe sandboxes
- **Cryptography:** hashing, AES, steganography, Hashcat
- **CTF training:** TryHackMe, picoCTF and weekly challenges
- **Guidance from the basics:** a five-step path from foundations to getting hired
- **Internships and jobs:** openings shared first with the community
- **Career guidance:** resume, portfolio and interview preparation

## 🖥️ Website features

- Clean, aesthetic white interface with an editorial serif and mono type pairing
- Animated loading screen with a progress bar and status messages
- Interactive particle network that reacts to the cursor
- Letter-by-letter animated hero and typing tagline
- Scrolling tool marquee and scroll progress bar
- Spotlight hover tiles for each learning track
- Step-by-step learning path and a Jobs & Internships section
- Founder spotlight with a floating badge
- Scroll reveal animations
- Fully responsive, with `prefers-reduced-motion` support
- Single file: HTML, CSS and JavaScript are all embedded, and the founder photo is embedded as base64

## 🚀 Getting started

No build step and nothing to install.

1. Download or clone this repository.
2. Open `evil-coders.html` in any modern browser.

To serve it locally instead, run these in the project folder, one at a time:

```powershell
python -m http.server 8000
```

```powershell
start http://localhost:8000/evil-coders.html
```

## 🌐 Deploy

Rename `evil-coders.html` to `index.html`, then deploy it to any static host:

- **GitHub Pages:** Settings → Pages → deploy from the `main` branch
- **Vercel / Netlify:** import the repository, no build command needed

## 🛠️ Customize

| What | Where |
| --- | --- |
| Colors | CSS variables in `:root` (`--ind`, `--ink`, `--paper`, `--peach`) |
| Fonts | Google Fonts link in `<head>` (Instrument Serif, Manrope, JetBrains Mono) |
| Founder photo | The `<img>` inside `.photo`, replace the base64 `src` with your own |
| Links and contacts | The `#join` section and the Careers buttons |
| Learning tracks | The `.bento` tiles inside `#craft` |
| Tagline lines | The `L` array in the script, next to the typing effect |
